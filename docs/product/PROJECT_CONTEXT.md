# Project Context

## Mission

Connect Christians in San Antonio with a church home and a growing body of faith.

## Product

An Airbnb-style directory: stunning church photos, clean filters, honest reviews, and
everything you need to plan a first visit (service times, directions, what to expect).

## Audience

- **Primary:** San Antonio residents looking for a church home (new to town or seeking change)
- **Secondary:** Visitors who want to attend a service while in town

## Non-goals

- Events calendars, forums, social features, or church admin tooling (cut in the 2026-11 overhaul)
- Donations, streaming, or theological recommendations
- Cities outside San Antonio (for now)
- Native apps — responsive web only

## Constraints

- Mobile-first and fast on free-tier hosting
- Accessible (WCAG 2.1 AA)
- Church data comes from public sources (Google Places + church websites)

## Stack

React 18 + Vite + Tailwind + TanStack Query · Express 4 + Prisma 5 + PostgreSQL/PostGIS ·
Mapbox GL · Render + Supabase.
